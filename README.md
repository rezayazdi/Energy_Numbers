# شماره ها | رستوران انرژی

نرم‌افزار ثبت نام و شماره تماس برای ویندوز (فونت وزیر، پد شماره، دارک‌مد).

## نصب

فایل نصب را از [Releases](../../releases) دانلود کنید:

`Energy Numbers Setup 1.4.0.exe`

بعد از نصب، میانبر دسکتاپ ساخته می‌شود و برنامه باز می‌شود. پیش‌نیاز ندارد.

## توسعه

```bash
npm install
npm start
npm run dist:win
```
